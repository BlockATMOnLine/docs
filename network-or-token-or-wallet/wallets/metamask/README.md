# MetaMask

MetaMask is a widely popular Web3 wallet, primarily available as a browser extension and mobile application. It helps users manage crypto assets, interact with decentralized applications (DApps), and connect to blockchain networks. Initially launched by ConsenSys in 2016 with a focus on the Ethereum ecosystem, it has since expanded to support multiple blockchains. Regarded as a "gateway" to the Web3 world, MetaMask is highly favored for its user-friendly design and broad compatibility.
