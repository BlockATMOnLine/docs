# Create TronLink Wallet

This guide will help you create a TronLink wallet in 3 minutes.

## Prerequisites

- ✅ Chrome, Firefox, or Brave browser
- ✅ Stable internet connection
- ✅ Paper and pen (for backing up recovery phrase)
- ⏱️ Estimated time: 3 minutes

## Step 1: Download TronLink

### Method A: Chrome Browser (Recommended)

1. Open [Chrome Web Store TronLink page](https://chrome.google.com/webstore/detail/tronlink/ibnejdfjmmkpcnlpebklmnkoeoihofec)
2. Click "Add to Chrome"
3. Confirm installation
4. After installation, TronLink icon appears in upper right corner of browser

### Method B: Official Website

1. Visit [tronlink.org](https://www.tronlink.org)
2. Click "Download"
3. Select your browser version or mobile app

{% hint style="warning" %}
**Security Reminder**:
- Only download TronLink from official channels
- Don't click download links in emails or social media
- Be vigilant against phishing websites
{% endhint %}

## Step 2: Create Wallet

1. Click TronLink icon in upper right corner of browser
2. First use will show welcome page
3. Click "Create Wallet"

## Step 3: Set Password

1. Enter wallet name (optional)
2. Set login password (at least 8 characters)
3. Confirm password
4. Check agreement box for terms of service
5. Click "Create"

{% hint style="info" %}
**Password Tips**:
- Use combination of uppercase, lowercase, numbers, and special characters
- Don't use easily guessed information
- Recommend using password manager
{% endhint %}

## Step 4: Backup Recovery Phrase (⚠️ Most Important)

{% hint style="danger" %}
**Warning**: The recovery phrase is the only way to recover your wallet. If lost, your assets will be permanently unrecoverable.
{% endhint %}

1. Click "Backup Recovery Phrase"
2. System will show 24-word recovery phrase
3. **Copy all words in order**
4. Recommend copying twice and storing in secure locations

### Secure Storage of Recovery Phrase

✅ **Correct Practices**:
- Write with pen on paper
- Store in safe or secure location
- Can store in bank safe deposit box

❌ **Wrong Practices**:
- Don't save screenshots
- Don't store on computer or phone
- Don't send via WeChat, email
- Don't tell anyone

## Step 5: Verify Recovery Phrase

1. System will require you to confirm recovery phrase
2. Click words in correct order
3. After verification passes, wallet creation is successful

## Step 6: Complete

Congratulations! Your TronLink wallet has been created successfully.

Now you can see:
- Your TRON address (starts with T)
- TRX balance
- TRC20 token list

## FAQ

### Can I create multiple wallets?

Yes. You can create multiple accounts in TronLink, each with an independent address.

### How to view wallet address?
1. Click TronLink icon
2. Click account name
3. Click copy icon to copy address
4. Address format: `T...` (34 characters, starts with T)

### How to add TRC20 tokens?
1. Open TronLink
2. Click "Discover" → "Add Token"
3. Enter token contract address
4. Token will be automatically added to list
