# TronLink 钱包

TronLink 是 TRON 网络官方钱包，专为 TRC20 代币设计。

## 产品概述

| 特性 | 说明 |
|------|------|
| 开发商 | Tron Foundation |
| 支持网络 | TRON (TRC20) |
| 平台 | 浏览器扩展、iOS、Android |
| 官网 | [tronlink.org](https://www.tronlink.org) |
| 下载 | [Chrome 商店](https://chrome.google.com/webstore/detail/tronlink/ibnejdfjmmkpcnlpebklmnkoeoihofec) |

## 为什么选择 TronLink？

### ✅ 优势

- **官方支持**：TRON 基金会官方钱包
- **TRC20 原生**：完美支持 TRC20 代币
- **低手续费**：TRON 网络转账费用低（~1 USDT）
- **快速确认**：交易 3-5 秒确认
- **操作简单**：界面友好，新手易用

### ⚠️ 限制

- **仅支持 TRON**：不支持 Ethereum 等其他网络
- **Gas 机制**：需要 TRX 作为能量

## 常见问题

### TronLink 安全吗？
是的，TronLink 是非托管钱包，私钥存储在本地。请从官方渠道下载并保护好密码。

### 可以创建多个账户吗？
是的。TronLink 支持创建多个账户，每个账户有独立地址。

### 需要 TRX 吗？
是的。TRON 网络转账需要消耗能量，建议使用 TRX 或租赁能量。
