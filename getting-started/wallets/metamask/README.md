# MetaMask

MetaMask 是全球最广泛使用的加密货币钱包，支持 Ethereum 和 Arbitrum 等 EVM 兼容网络。

## 产品概述

| 特性   | 说明                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------ |
| 开发商  | ConsenSys                                                                                        |
| 支持网络 | Ethereum, Arbitrum, BSC, Polygon 等                                                               |
| 平台   | 浏览器扩展、iOS、Android                                                                                |
| 官网   | [metamask.io](https://metamask.io)                                                               |
| 下载   | [Chrome 商店](https://chrome.google.com/webstore/detail/metamask/nkbihfbeogaeaoehlefnkodbefgpgknn) |

## 支持的 BlockATM 网络

| 网络               | 代币类型              | Gas 代币         |
| ---------------- | ----------------- | -------------- |
| Ethereum (ERC20) | USDT, USDC, DAI 等 | ETH            |
| Arbitrum (ARB20) | USDT, USDC 等      | ETH (Arbitrum) |

{% hint style="info" %}
**提示**：TRON 网络需要使用 TronLink 钱包，MetaMask 不支持 TRON 网络。
{% endhint %}

## 常见问题

### MetaMask 安全吗？

是的，MetaMask 是非托管钱包，您的私钥存储在本地设备上。但请确保：

* 从官方渠道下载
* 保护好助记词
* 不点击可疑链接

### 可以在多个设备使用吗？

可以。使用助记词可以在多个设备恢复同一个钱包。

### 忘记助记词怎么办？

如果未备份助记词，卸载后将无法恢复钱包。请务必在创建时备份。
