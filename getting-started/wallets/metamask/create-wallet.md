# Create MetaMask Wallet

This guide will help you create a MetaMask wallet in 5 minutes.

## Prerequisites

- ✅ Chrome, Firefox, or Brave browser
- ✅ Stable internet connection
- ✅ Paper and pen (for backing up recovery phrase)
- ⏱️ Estimated time: 5 minutes

## Step 1: Download MetaMask

### Method A: Chrome Browser (Recommended)

1. Open [Chrome Web Store MetaMask page](https://chrome.google.com/webstore/detail/metamask/nkbihfbeogaeaoehlefnkodbefgpgknn)
2. Click "Add to Chrome"
3. Confirm installation

### Method B: Official Website

1. Visit [metamask.io](https://metamask.io)
2. Click "Download"
3. Select your browser version

{% hint style="warning" %}
**Security Reminder**:
- Only download MetaMask from official channels
- Don't click download links in emails or social media
- Be vigilant against phishing websites
{% endhint %}

## Step 2: Create Wallet

1. After installation, click MetaMask icon in upper right corner of browser
2. Click "Create a New Wallet"
3. Read and agree to terms of use

## Step 3: Create Password

1. Enter a strong password (at least 8 characters)
2. Confirm password
3. Check the agreement box
4. Click "Create"

{% hint style="info" %}
**Password Tips**:
- Use combination of uppercase, lowercase, numbers, and special characters
- Don't use easily guessed information like birthdays or phone numbers
- Recommend using password manager to save password
{% endhint %}

## Step 4: Backup Recovery Phrase (⚠️ Most Important)

{% hint style="danger" %}
**Warning**: The recovery phrase is the only way to recover your wallet. If lost, your assets will be permanently unrecoverable. BlockATM cannot help you recover the recovery phrase.
{% endhint %}

1. Click "Click here to backup"
2. Write down 12 words in order (one word per line)
3. **Important**: Copy exactly in order, do not shuffle
4. Recommend copying twice and storing in different places

### Secure Storage of Recovery Phrase

✅ **Correct Practices**:
- Write with pen on paper
- Store in safe or secure location
- Can store in bank safe deposit box

❌ **Wrong Practices**:
- Don't save screenshots
- Don't store on computer or phone
- Don't send via WeChat, email
- Don't tell anyone

## Step 5: Verify Recovery Phrase

1. System will require you to select words in order
2. Click words in the order you just copied
3. After verification passes, wallet creation is successful

## Step 6: Complete

Congratulations! Your MetaMask wallet has been created successfully.

Now you can:
- View your wallet address
- Receive cryptocurrency
- Connect to BlockATM admin dashboard

## FAQ

### Can I create multiple wallets?

Yes. You can create multiple accounts in MetaMask, each with an independent address.

### What's the difference between recovery phrase and private key?
- Recovery phrase: 12 words that can restore the entire wallet (including all accounts)
- Private key: Key for a single account, can only control that account

### How to view wallet address?
1. Click MetaMask icon
2. Click copy icon on the right side of account name
3. Address format: `0x...` (42 characters)
