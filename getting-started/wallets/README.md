# 钱包教程

BlockATM 支持多种加密货币钱包，您可以根据业务需求选择合适的钱包。

## 支持的钱包类型

| 钱包类型 | 支持网络 | 适合场景 | 难度 |
|---------|---------|---------|------|
| [MetaMask](metamask/) | Ethereum, Arbitrum | 桌面端、开发者 | ⭐⭐ |
| [TronLink](tronlink/) | TRON | TRON 网络专用 | ⭐ |
| [WalletConnect](walletconnect/) | 多网络 | 移动端 H5 | ⭐⭐ |

## 选择建议

### MetaMask
- ✅ 最广泛使用的 EVM 钱包
- ✅ 支持 Ethereum 和 Arbitrum 网络
- ✅ 浏览器扩展 + 移动 App
- ⚠️ 需要安装浏览器插件

**适合**：桌面端应用、开发者、多链业务

### TronLink
- ✅ TRON 网络官方钱包
- ✅ 操作简单，上手快
- ✅ 支持 TRC20 代币
- ⚠️ 仅支持 TRON 网络

**适合**：专注 TRON 网络的业务

### WalletConnect
- ✅ 支持移动端钱包（Trust Wallet、TokenPocket 等）
- ✅ 无需安装特定钱包
- ✅ 扫码连接，体验好
- ⚠️ 需要用户已有兼容钱包

**适合**：移动端 H5 应用、希望支持多种钱包

## 安全提示

{% hint style="warning" %}
**重要安全建议**：

1. **保护助记词**：永远不要向任何人透露您的助记词或私钥
2. **使用硬件钱包**：大额资金建议使用 Ledger、Trezor 等硬件钱包
3. **小额测试**：首次使用先进行小额测试
4. **验证地址**：转账前仔细核对收款地址
{% endhint %}
