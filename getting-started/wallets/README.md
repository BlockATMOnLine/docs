# Wallet Tutorials

BlockATM supports various cryptocurrency wallets. You can choose the appropriate wallet based on your business needs.

## Supported Wallet Types

| Wallet Type | Supported Networks | Best For | Difficulty |
|---------|---------|---------|------|
| [MetaMask](metamask/) | Ethereum, Arbitrum | Desktop, Developers | ⭐⭐ |
| [TronLink](tronlink/) | TRON | TRON Network Only | ⭐ |
| [WalletConnect](walletconnect/) | Multi-network | Mobile H5 | ⭐⭐ |

## Selection Advice

### MetaMask
- ✅ Most widely used EVM wallet
- ✅ Supports Ethereum and Arbitrum networks
- ✅ Browser extension + Mobile app
- ⚠️ Browser extension required

**Suitable for**: Desktop applications, developers, multi-chain business

### TronLink
- ✅ Official TRON network wallet
- ✅ Simple operation, easy to use
- ✅ Supports TRC20 tokens
- ⚠️ TRON network only

**Suitable for**: Businesses focused on TRON network

### WalletConnect
- ✅ Supports mobile wallets (Trust Wallet, TokenPocket, etc.)
- ✅ No specific wallet installation required
- ✅ QR code connection, good experience
- ⚠️ User must have a compatible wallet

**Suitable for**: Mobile H5 applications, wanting to support multiple wallets

## Security Tips

{% hint style="warning" %}
**Important Security Recommendations**:

1. **Protect Recovery Phrase**: Never share your recovery phrase or private key with anyone
2. **Use Hardware Wallet**: For large funds, recommend hardware wallets like Ledger, Trezor
3. **Small Amount Testing**: Test with small amounts first
4. **Verify Address**: Double-check recipient address before transfer
{% endhint %}
