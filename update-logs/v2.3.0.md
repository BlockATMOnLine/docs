# V2.3.0

**Production Update Time:** 2026.01.13

**Please note: This update is backward-compatible and will not affect existing integrations.**

#### Key Updates:

* **Added Contract Approve Management Page**: Introduced a visual management interface for monitoring on-chain token approval limits, providing real-time authorization status, remaining allowance, and recommended approval values.
* **Added Allowance-Based Payout Mode**: Introduced a payout mechanism based on on-chain token approvals, eliminating the need for funds to be deposited in contracts, reducing security risks and supporting large-scale payout scenarios.
* **Added Allowance-Based Payout Contract Creation**: Support for creating allowance-based payout contracts with configurable funding wallet addresses and payout signature addresses.
* **Optimized Payout Order Process**: Adjusted balance display dimensions, added "Available Allowance" calculation logic (taking the minimum value between approval limit and wallet balance), and improved prompts and guidance when allowance is insufficient.
* **Optimized Asset Management Page**: Allowance-based contracts display "Authorization Management" button and hide "Deposit" button, with new hover tooltips for approval limits.
* **Added Monitoring and Alerting Capabilities**: Established monitoring metrics and alerting rules around approval limits, available balances, and large-scale operations.
* **Optimized Contract Creation Flow**: Added mode selection popup to distinguish between balance-based and allowance-based payout modes, with optimized configuration form fields.

Let me know if you'd like any adjustments!
