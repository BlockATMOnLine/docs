# 创建 TronLink 钱包

本指南将帮助您在 3 分钟内创建 TronLink 钱包。

## 前置准备

- ✅ Chrome、Firefox 或 Brave 浏览器
- ✅ 稳定的网络连接
- ✅ 纸和笔（用于备份助记词）
- ⏱️ 预计时间：3 分钟

## 步骤 1：下载 TronLink

### 方式 A：Chrome 浏览器（推荐）

1. 打开 [Chrome 网上应用店 TronLink 页面](https://chrome.google.com/webstore/detail/tronlink/ibnejdfjmmkpcnlpebklmnkoeoihofec)
2. 点击"添加到 Chrome"
3. 确认安装
4. 安装完成后，浏览器右上角会出现 TronLink 图标

### 方式 B：官方网站

1. 访问 [tronlink.org](https://www.tronlink.org)
2. 点击"Download"
3. 选择您的浏览器版本或移动端 App

{% hint style="warning" %}
**安全提醒**：
- 只从官方渠道下载 TronLink
- 不要点击邮件或社交媒体中的下载链接
- 警惕钓鱼网站
{% endhint %}

## 步骤 2：创建钱包

1. 点击浏览器右上角的 TronLink 图标
2. 首次使用会看到欢迎页面
3. 点击"创建钱包"（Create Wallet）

## 步骤 3：设置密码

1. 输入钱包名称（可选）
2. 设置登录密码（至少 8 个字符）
3. 确认密码
4. 勾选同意服务条款
5. 点击"创建"

{% hint style="info" %}
**密码提示**：
- 使用大小写字母、数字和特殊字符组合
- 不要使用容易被猜到的信息
- 建议使用密码管理器保存
{% endhint %}

## 步骤 4：备份助记词（⚠️ 最重要）

{% hint style="danger" %}
**警告**：助记词是恢复钱包的唯一方式。如果丢失，您的资产将永远无法找回。
{% endhint %}

1. 点击"备份助记词"
2. 系统会显示 24 个单词的助记词
3. **按顺序**抄下所有单词
4. 建议抄写两份，分别存放在安全的地方

### 助记词安全存储

✅ **正确做法**：
- 用笔写在纸上
- 存放在保险箱或安全的地方
- 可以存放在银行的保险柜

❌ **错误做法**：
- 不要截图保存
- 不要存储在电脑或手机里
- 不要通过微信、邮件发送
- 不要告诉任何人

## 步骤 5：验证助记词

1. 系统会要求您确认助记词
2. 按照正确的顺序点击单词
3. 验证通过后，钱包创建成功

## 步骤 6：完成

恭喜！您的 TronLink 钱包已创建成功。

您现在可以看到：
- 您的 TRON 地址（以 T 开头）
- TRX 余额
- TRC20 代币列表

## 获取测试 TRX

在测试环境使用前，需要获取测试 TRX：

1. 访问 [TRON Nile 测试网水龙头](https://nileex.io/join/getJoinPage)
2. 输入您的钱包地址
3. 点击"Get TRX"
4. 等待 1-2 分钟到账

{% hint style="info" %}
**提示**：测试 TRX 仅用于测试环境，不能用于生产环境。
{% endhint %}

## 常见问题

### 可以创建多个钱包吗？
是的。在 TronLink 中可以创建多个账户，每个账户有独立的地址。

### 如何查看钱包地址？
1. 点击 TronLink 图标
2. 点击账户名称
3. 点击复制图标复制地址
4. 地址格式：`T...`（34 个字符，以 T 开头）

### 如何添加 TRC20 代币？
1. 打开 TronLink
2. 点击"发现" → "添加代币"
3. 输入代币合约地址
4. 代币会自动添加到列表
