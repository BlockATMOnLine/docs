# 创建 MetaMask 钱包

本指南将帮助您在 5 分钟内创建 MetaMask 钱包。

## 前置准备

- ✅ Chrome、Firefox 或 Brave 浏览器
- ✅ 稳定的网络连接
- ✅ 纸和笔（用于备份助记词）
- ⏱️ 预计时间：5 分钟

## 步骤 1：下载 MetaMask

### 方式 A：Chrome 浏览器（推荐）

1. 打开 [Chrome 网上应用店](https://chrome.google.com/webstore/detail/metamask/nkbihfbeogaeaoehlefnkodbefgpgknn)
2. 点击"添加到 Chrome"
3. 确认安装

### 方式 B：官方网站

1. 访问 [metamask.io](https://metamask.io)
2. 点击"Download"
3. 选择您的浏览器版本

{% hint style="warning" %}
**安全提醒**：
- 只从官方渠道下载 MetaMask
- 不要点击邮件或社交媒体中的下载链接
- 警惕钓鱼网站
{% endhint %}

## 步骤 2：创建钱包

1. 安装完成后，点击浏览器右上角的 MetaMask 图标
2. 点击"创建新钱包"（Create a New Wallet）
3. 阅读并同意使用条款

## 步骤 3：创建密码

1. 输入一个强密码（至少 8 个字符）
2. 确认密码
3. 勾选同意条款
4. 点击"创建"

{% hint style="info" %}
**密码提示**：
- 使用大小写字母、数字和特殊字符组合
- 不要使用生日、电话号码等容易被猜到的信息
- 建议使用密码管理器保存密码
{% endhint %}

## 步骤 4：备份助记词（⚠️ 最重要）

{% hint style="danger" %}
**警告**：助记词是恢复钱包的唯一方式。如果丢失，您的资产将永远无法找回。BlockATM 无法帮助您恢复助记词。
{% endhint %}

1. 点击"点击此处备份"（Click here to backup）
2. 按顺序写下 12 个单词（每个单词一行）
3. **重要**：务必按顺序抄写，不要打乱顺序
4. 建议抄写两份，分别存放在不同地方

### 助记词安全存储

✅ **正确做法**：
- 用笔写在纸上
- 存放在保险箱或安全的地方
- 可以存放在银行的保险柜

❌ **错误做法**：
- 不要截图保存
- 不要存储在电脑或手机里
- 不要通过微信、邮件发送
- 不要告诉任何人

## 步骤 5：验证助记词

1. 系统会要求您按顺序选择单词
2. 按照刚才抄写的助记词顺序点击
3. 验证通过后，钱包创建成功

## 步骤 6：完成

恭喜！您的 MetaMask 钱包已创建成功。

现在您可以：
- 查看您的钱包地址
- 接收加密货币
- 连接 BlockATM 管理后台

## 常见问题

### 可以创建多个钱包吗？
是的。在 MetaMask 中可以创建多个账户，每个账户有独立的地址。

### 助记词和私钥有什么区别？
- 助记词：12 个单词，可以恢复整个钱包（包括所有账户）
- 私钥：单个账户的密钥，只能控制该账户

### 如何查看钱包地址？
1. 点击 MetaMask 图标
2. 点击账户名称右侧的复制图标
3. 地址格式：`0x...`（42 个字符）
