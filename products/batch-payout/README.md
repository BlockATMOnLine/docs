# 付币概述

Batch Payout 是 BlockATM 提供的加密货币批量支付解决方案，支持余额支付和授权支付两种模式。

## 产品特点

* ✅ **批量处理**：支持一次性发起多笔付币
* ✅ **双付币方式**：余额付币 + 授权付币，灵活选择
* ✅ **自托管**：资金完全由您控制
* ✅ **多链支持**：TRON、Ethereum、Arbitrum
* ✅ **透明费率**：固定费用，无隐藏收费

## 付币方式

### 余额付币 (Balance Mode)

资金预先存入合约，付币时从合约余额扣除。

**适用场景**：

* 日常高频固定金额付币（如工资发放）
* 商户已有资金在合约中

### 授权付币 (Allowance Mode)

用户授权合约支配其资金，无需预存到合约。

**适用场景**：

* 需要提高资金效率
* 不想让资金预存在合约中
* 大规模批量付币

[了解授权模式 →](allowance-mode.md)
