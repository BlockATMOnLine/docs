# 付币费用说明

Batch Payout 付币服务的详细费用说明。

## 费用概览

| 类型 | 费用 | 收费时机 |
|------|------|---------|
| 创建合约 | 200 USD/个 | 合约创建时 |
| 付币 | 1 USD/笔 | 付币执行时 |

{% hint style="info" %}
**费用币种**：所有费用以稳定币（如 USDT、USDC）收取，汇率固定为 1:1。
{% endhint %}

## 详细说明

### 创建合约费用

每创建一个付币合约，收取 200 USD 的服务费。

| 合约类型 | 费用 |
|---------|------|
| 余额模式合约 | 200 USDT |
| 授权模式合约 | 200 USDT |

### 付币手续费

| 费用项 | 金额 |
|-------|------|
| 固定手续费 | 1 USD/笔 |

**示例**：您向用户支付 1000 USDT，手续费为 1 USDT，实际扣除 1001 USDT（余额模式从合约扣，授权模式从用户授权额度扣）。

## 费用计算示例

### 场景 1：单笔付币

```javascript
// 商户发起付币
付币金额：1000 USDT
手续费：1 USDT
总扣除：1001 USDT
```

### 场景 2：批量付币

```javascript
// 商户发起批量付币 3 笔
订单 1：500 USDT
订单 2：300 USDT
订单 3：200 USDT

总付币金额：1000 USDT
手续费：3 USDT (1 USDT × 3 笔)
总扣除：1003 USDT
```

{% hint style="info" %}
**批量付币**：每笔订单单独计算手续费，不因批量而优惠。
{% endhint %}

### 场景 3：授权付币

```javascript
// 用户授权 5000 USDT 给合约
// 商户发起付币 1000 USDT

付币金额：1000 USDT
手续费：1 USDT
总扣除：1001 USDT（从用户授权额度扣除）

用户剩余授权额度：5000 - 1001 = 3999 USDT
```

## 与收币费用对比

| 对比项 | 收币 | 付币 |
|-------|------|------|
| 创建合约 | 200 USD | 200 USD |
| 交易手续费 | 2 USD 或 0.4% | 1 USD |
| 收费对象 | 商户 | 商户 |

## 常见问题

**Q：授权付币和余额付币手续费相同吗？**

A：相同，都是 1 USD/笔。

**Q：付币失败收取手续费吗？**

A：不收取，只有成功执行的付币才收取手续费。

**Q：可以自定义手续费率吗？**

A：当前不支持自定义，费用标准固定。

**Q：测试环境需要支付手续费吗？**

A：测试环境使用测试代币，没有实际费用。
