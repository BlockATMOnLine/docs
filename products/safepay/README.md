# 收币概述

Safepay 是 BlockATM 提供的加密货币收款解决方案，支持两种收款方式。

<div align="left"><figure><img src="../../.gitbook/assets/image (11).png" alt="" width="375"><figcaption></figcaption></figure></div>

## 产品特点

* ✅ **自托管**：资金直接转入您的智能合约，完全自主控制
* ✅ **多方式**：支持钱包连接支付和扫码支付
* ✅ **多链支持**：TRON (TRC20)、Ethereum (ERC20)、Arbitrum (ARB20)
* ✅ **实时到账**：区块链确认后立即到账，无需等待结算
* ✅ **无需 KYB/KYC**：去中心化应用，无需身份认证

## 收款方式

### Web3 收款（钱包连接）

用户通过钱包（如 MetaMask、TronLink）连接您的收银台，授权智能合约完成支付。

**特点**：

* 用户体验流畅，适合桌面端
* 支持各种 ERC20/TRC20 代币
* 支付金额准确，无手动输入错误

<div align="left"><figure><img src="../../.gitbook/assets/image (12).png" alt="" width="375"><figcaption></figcaption></figure></div>

### Scan2Pay（扫码支付）

用户扫描收银台显示的收款二维码，使用钱包扫码完成支付。

**特点**：

* 适合移动端用户
* 无需连接钱包操作
* 兼容各种移动钱包 App

<div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt="" width="375"><figcaption></figcaption></figure></div>

## 适用场景

| 场景      | 推荐方式     |
| ------- | -------- |
| 电商网站收款  | Web3 收款  |
| 移动端应用   | Scan2Pay |
| 线下收款    | Scan2Pay |
| DApp 内购 | Web3 收款  |
