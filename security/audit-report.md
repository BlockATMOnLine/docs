# 合约审计

BlockATM 的智能合约已通过安全审计。

## 审计报告

BlockATM 智能合约由知名安全审计机构进行审计，审计报告可在管理后台下载，或联系技术支持获取。

## 审计范围

| 合约 | 说明 |
|------|------|
| 收币合约 | Safepay 收款合约 |
| 付币合约 | Batch Payout 付币合约 |

## 安全特性

### 权限控制

- **Owner 权限**：合约创建者，拥有管理权限
- **Signer/Packer 权限**：执行资金操作，需要签名验证
- **白名单机制**：收款人必须在白名单中

### 签名验证

所有合约操作都需要签名验证：
- HMAC-SHA256 签名算法
- 时间戳防重放
- Nonce 防重复

### 事件监控

- 所有关键操作都会触发事件
- BlockATM 服务端实时监听链上事件
- 异常情况自动告警

## 安全建议

{% hint style="warning" %}
**重要安全建议**：

1. **使用硬件钱包**：Owner 和 Signer 地址建议使用硬件钱包管理
2. **保护密钥**：API Key 和 Secret Key 不要泄露
3. **验证地址**：提币时验证收款地址是否正确
4. **小额测试**：首次使用先小额测试
{% endhint %}
