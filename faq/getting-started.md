# 入门问题

关于 BlockATM 入门相关的常见问题。

## 如何创建钱包？

BlockATM 支持以下钱包：

| 钱包 | 支持网络 | 平台 |
|------|---------|------|
| **MetaMask** | Ethereum, Arbitrum | Chrome 插件, Mobile |
| **TronLink** | TRON | Chrome 插件, Mobile |
| **WalletConnect** | 全部 | Mobile DApp |

**创建步骤**：
1. 下载并安装钱包插件/ App
2. 按照钱包引导创建或导入钱包
3. 备份好助记词

{% hint style="warning" %}
**重要**：助记词是您钱包的唯一凭证，切勿泄露给他人！
{% endhint %}

## 需要 KYB/KYC 吗？

**不需要**。

BlockATM 是去中心化应用（DApp），运行在区块链上。您不需要向任何机构提交身份证明材料即可使用。

## 如何获取测试币？

在测试环境开发时，您需要获取测试网的代币：

### TRON 测试网 (Nile)
- 访问 [TRON Nile 水龙头](https://nile.tronscan.org/#/faucet)
- 输入您的 TRON 钱包地址
- 获取 Test TRX

### Ethereum Sepolia 测试网
- 访问 [Alchemy 水龙头](https://www.alchemy.com/faucets/sepolia)
- 或 [QuickNode 水龙头](https://quicknode.com/faucet/sepolia)
- 输入您的 Ethereum 钱包地址
- 获取 Sepolia ETH

### Arbitrum Sepolia 测试网
- 通过 [官方跨链桥](https://bridge.arbitrum.io/?destinationChain=arbitrum-sepolia&sourceChain=sepolia) 从 Ethereum Sepolia 转账
- 或访问 [Arbitrum Sepolia 水龙头](https://bridge.arbitrum.io/)
- 获取 Test ARB
