# 收币问题

关于收币功能的常见问题。

## 收币有最低金额限制吗？

**没有硬性限制**。

但建议设置合理的最低金额，因为区块链转账有 Gas 费用，小额支付可能不划算。

| 网络 | 建议最低金额 |
|------|-------------|
| TRON | 1 USD |
| Ethereum | 10 USD |
| Arbitrum | 1 USD |

**链上失败**：检查钱包授权或网络状态

异常订单处理完成后，原订单号不可重用，需要创建新订单。

## TRC20 和 ERC20 哪个更好？

| 对比项 | TRC20 | ERC20 |
|-------|-------|-------|
| 手续费 | 低（~1 TRX） | 高（$0.1-$5） |
| 速度 | 快（3 秒） | 慢（15-30 秒） |
| 生态 | TRON 生态 | Ethereum 生态 |

**建议**：
- 大额支付：推荐 TRC20（手续费低）
- 需要 Ethereum 生态：使用 ERC20

## 用户支付后多久到账？

| 网络 | 确认时间 |
|------|---------|
| TRON | ~3 秒（1 个确认） |
| Ethereum | ~1 分钟（12 个确认） |
| Arbitrum | ~1-3 分钟（1 个确认） |

{% hint style="info" %}
**到账标准**：区块链确认后即为到账，BlockATM 会立即更新订单状态并发送 Webhook 通知。
{% endhint %}

## 可以退款吗？

BlockATM 作为支付通道不提供自动退款功能。

**解决方案**：
- 通过管理后台手动执行退款（从合约提取资金后退回用户）
- 或通过付币功能向用户退款

## Scan2Pay 金额输错了怎么办？

Scan2Pay 要求用户支付的金额与订单金额完全一致。

**金额不匹配后果**：
- 订单无法自动关联
- 资金可能丢失

**建议**：
1. 提示用户支付前确认金额
2. 用户输错金额时，联系技术支持处理

## 如何查看收币记录？

1. 登录 BlockATM 管理后台
2. 进入「收币」→「订单列表」
3. 可按时间、状态、订单号等筛选

或通过 API 查询：
```
GET /order/api/v2/payorder/list
```
