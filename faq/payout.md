# 付币问题

关于付币功能的常见问题。

## 余额付币和授权付币有什么区别？

| 对比项 | 余额模式 | 授权模式 |
|-------|---------|---------|
| 资金位置 | 合约余额 | 用户钱包余额 |
| 预先充值 | 需要 | 不需要 |
| 授权 | 无需 | 需要用户授权 |
| 资金风险 | 合约风险 | 用户钱包风险 |

**选择建议**：
- 资金已在合约：使用余额模式
- 需要灵活调度：使用授权模式



## 授权额度如何计算？

实际可用额度 = min(授权额度, 钱包余额)

**示例**：
```
用户授权额度：5000 USDT
用户钱包余额：3000 USDT
实际可用额度：3000 USDT
```



## 付币多久到账？

| 网络 | 到账时间 |
|------|---------|
| TRON | 即时（~3 秒） |
| Ethereum | 15-30 秒 |
| Arbitrum | 即时（~1-3 分钟） |

{% hint style="info" %}
**到账时间**指区块链确认时间，实际到账还取决于网络拥堵情况。
{% endhint %}

## 付币失败怎么办？

| 失败原因 | 解决方法 |
|---------|---------|
| 余额不足 | 充值到合约 |
| 授权不足 | 用户增加授权额度 |
| 白名单限制 | 将地址加入白名单（余额模式） |
| 签名验证失败 | 检查签名密钥和算法 |

## 可以批量付币吗？

是的，支持批量付币。

**批量接口**：
```
POST /order/api/v2/payout/batch
```

**限制**：
- 单笔订单金额不能为 0
- 批量订单总数有限制（联系技术支持了解）

## 授权付币需要用户操作吗？

是的，授权付币需要用户预先授权合约支配其代币。

**用户操作步骤**：
1. 在钱包中（Tronscan / Etherscan）执行授权
2. 或通过 BlockATM 管理后台引导授权

{% hint style="info" %}
**授权只需一次**：用户授权后，额度内可多次付币，无需每次授权。
{% endhint %}

## 如何撤回授权？

在钱包中调用：

```
approve(合约地址, 0)
```

或直接通过 [Tronscan](https://tronscan.org) / [Etherscan](https://etherscan.io) 执行。

## 合约余额有上限吗？

没有上限，但建议：

- 单笔付币金额不要过大
- 大额支付分批执行
