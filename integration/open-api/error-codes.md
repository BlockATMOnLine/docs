# 错误码

BlockATM API 的完整错误码对照表。

## 系统错误 (000xxx)

| code | 说明 |
|------|------|
| 000101 | 系统错误 |
| 000102 | 参数类型错误 |
| 000103 | 缺少必填参数 |
| 000104 | 对象不能为空 |
| 000105 | 请求无效 |
| 000106 | 重复请求 |
| 000107 | 系统繁忙 |
| 000108 | Token 必填 |
| 000109 | 会话已过期 |
| 000110 | 无访问权限 |
| 000112 | API Key 必填 |
| 000113 | 服务不可用，请稍后重试 |
| 000114 | 服务维护中 |

## 业务错误 (0002xx)

| code | 说明 |
|------|------|
| 000201 | 数据已存在 |
| 000202 | 数据不存在 |
| 000203 | 数据无变化 |
| 000204 | 状态无效 |
| 000205 | 服务请求失败 |
| 000206 | 字段超过最大长度 |
| 000207 | 字段低于最小长度 |
| 000208 | 不支持的文件格式 |

## 支付错误 (0003xx)

| code | 说明 |
|------|------|
| 000301 | 订单已支付 |
| 000302 | 订单已取消 |
| 000303 | 订单已过期 |
| 000304 | 订单金额不匹配 |
| 000305 | 支付方式不可用 |
| 000306 | 签名验证失败 |
| 000307 | 余额不足 |
| 000308 | 授权额度不足 |

## 合约错误 (0004xx)

| code | 说明 |
|------|------|
| 000401 | 合约不存在 |
| 000402 | 合约地址无效 |
| 000403 | 合约余额不足 |
| 000404 | 不支持的代币 |
| 000405 | 收款地址不在白名单 |

## 处理建议

| 错误类型 | 建议处理 |
|---------|---------|
| 000101/000107 | 系统错误，等待后重试 |
| 000103/000105 | 检查请求参数 |
| 000202 | 检查订单/合约是否存在 |
| 000303 | 订单已过期，重新创建 |
| 000306 | 检查签名是否正确 |
| 000307/000308 | 充值或增加授权额度 |
