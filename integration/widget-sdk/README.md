# Widget SDK

Widget SDK is the fastest way to integrate BlockATM. You can embed a cryptocurrency cashier in your application in just three steps.

## Features

- ✅ **Fast Integration**: Complete integration within 30 minutes
- ✅ **No Backend Required**: Signature can be completed on frontend
- ✅ **Multiple Payment Methods**: Support wallet connect and scan payment
- ✅ **Multi-chain Support**: TRON, Ethereum, Arbitrum

## Supported Environments

| Environment | URL |
|------|-----|
| Production | `https://pay.blockatm.net/libs/v2/BlockATM.umd.js` |
| Test | `https://test-pay.blockatm.net/libs/v2/BlockATM.umd.js` |

## Integration Flow

1. Import SDK in HTML
2. Initialize SDK
3. Invoke cashier
