# V2.3.0 更新日志

> **发布日期**：2026-01-13
> **版本**：V2.3.0

---

## 概述

V2.3.0 引入了**授权管理模式**，允许用户授权合约支配其代币，无需预存资金到合约。

## 主要更新

### 新增功能

| 功能 | 说明 |
|------|------|
| 授权管理页面 | 可视化管理授权状态 |
| 授权付币模式 | 基于链上授权额度的付币 |
| 授权付币合约 | 支持授权付币的新合约类型 |
| 监控告警 | 授权额度监控和告警 |

## 授权管理模式

### 工作原理

```mermaid
graph LR
    User[用户钱包] -->|授权| Contract[付币合约]
    Contract -->|提取| Recipient[收款人]
    
    style Contract fill:#e1f5ff
```

### 核心特点

| 特点 | 说明 |
|------|------|
| 无需预存 | 用户授权即可，无需充值到合约 |
| 链上验证 | 授权额度实时从链上查询 |
| 灵活调度 | 可从多个授权地址支付 |

## 合约创建增强

### 新增配置

创建付币合约时新增模式选择：

| 模式 | 说明 |
|------|------|
| 余额模式 | 传统模式，资金预存到合约 |
| 授权模式 | 新模式，基于用户授权 |

## 资产页面优化

### 授权管理入口

- 授权模式合约显示"授权管理"按钮
- 隐藏"充值"按钮
- 新增授权额度悬浮提示
