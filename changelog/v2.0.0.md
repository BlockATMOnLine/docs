# V2.0.0 Changelog

> **Release Date**: 2025-04-17
> **Version**: V2.0.0
> **Compatibility**: Not backward compatible, integration upgrade required

---

## Version Overview

V2.0.0 is a major version upgrade for BlockATM, bringing a completely new cashier integration method and comprehensive upgrade of API signature algorithm.

{% hint style="warning" %}
**Important Upgrade Notice**:

- API path upgraded from `/api/v1` to `/api/v2`
- Signature algorithm upgraded from ECDSA to HMAC-SHA256
- Widget SDK upgraded to v2 version

Existing integrations need to be upgraded according to the migration guide.
{% endhint %}

---

## Major Changes

### 1. Cashier Integration Upgrade

#### Change Comparison

| Change Item | Old Version | New Version |
|------------|--------|--------|
| SDK Version | v1 | **v2** |
| SDK URL | `https://cashier.blockatm.net/libs/v2/BlockATM.umd.js` | **Unchanged** |
| custNo Parameter | Optional | **Required** |
| URL Signature | Optional ECDSA | **Required HMAC-SHA256** |

#### Migration Steps

```
1. Confirm if custNo parameter is passed in your code
2. Implement HMAC-SHA256 signature logic
3. Update SDK reference URL
4. Test and verify
```

Detailed documentation: [Widget SDK Integration](../integration/widget-sdk/integration.md)

---

### 2. Scan-to-Pay Integration Upgrade

#### Change Comparison

| Change Item | Old Version | New Version |
|------------|--------|--------|
| Integration Method | API call to get cashier URL | **Widget component integration** |

#### Migration Steps

```
1. Stop using the old API call method
2. Integrate the new Widget component
3. Remove the old cashier URL redirect logic
```

Detailed documentation: [Collection Integration Guide](../integration/guides/collect-guide.md)

---

### 3. Payout API Addition

#### New Features

| Feature | Description |
|------|------|
| API Create Payout Order | New `/order/api/v2/payout/order` endpoint |
| Original Upload Method Retained | Merchant-side upload method retained |

#### API Documentation

[Create Payout Order API](../integration/open-api/payout-api.md)

---

### 4. Webhook Upgrade

#### Change Comparison

| Change Item | Old Version | New Version |
|------------|--------|--------|
| Signature Algorithm | ECDSA | **HMAC-SHA256** |
| Status Field | Integer (int) | **String** |

#### Status Code Changes

| Old Status Code | New Status Code | Description |
|----------|----------|------|
| -1 | CANCELLED | Cancelled |
| -1 | EXPIRED | Expired |
| 0 | PENDING | Pending |
| 1 | SUCCESS | Success |

Detailed documentation: [Webhook Signature Verification](../integration/webhooks/verification.md)

---

### 5. API Path Upgrade

#### Change Reference Table

| Feature | Old Path | New Path |
|------|--------|--------|
| Get Supported Networks | `/api/v1/public/networklist` | `/api/v2/pub/allNetworks` |
| Get Supported Tokens | `/api/v1/public/cryptocurrencies` | `/api/v2/pub/symbolList` |
| Get Cashier Info | `/api/v1/contract/payment` | `/api/v2/pub/cashier/info` |
| Query Payment Order | `/api/v1/payment/qrCodePayment` | `/order/api/v2/payorder/detail` |
| Query Payout Order | `/api/v1/payout/get` | `/order/api/v2/payout/detail` |

## Field Change Details

### Webhook Field Changes

| Old Field | New Field | Type | Description |
|--------|--------|------|------|
| platOrderNo | id | long | BlockATM order unique identifier |
| type | orderType | int | Payment order type |
| status | status | String | Status: PENDING/SUCCESS etc. |
| walletAddress | fromAddress | String | Paying wallet address |
| merchantId | cashierId | long | Cashier ID |
| - | blockTime | long | Blockchain transaction creation time |
| fee | - | number | Old fee field removed |

## Signature Change Details

### Configuration Location Changes

| Configuration Item | Old Location | New Location |
|--------|--------|--------|

| Webhook URL | Collection Contract → Settings → Webhook | **Cashier → Integration** |

| Item | Old Version | New Version |
|------|--------|--------|

## Compatibility Notes

{% hint style="danger" %}
**Not Backward Compatible**: V2.0.0 is not backward compatible with old integrations. Please ensure all migration work is completed before upgrading.
{% endhint %}

### Recommended Upgrade Strategy

```
1. Complete all migration in test environment
2. Use test API Key for full flow testing
3. Verify collection, payout, and Webhook functions work correctly
4. Switch to production API Key in production environment
5. Monitor for 24 hours to confirm normal operation
```
