# V2.0.0 更新日志

> **发布日期**：2025-04-17
> **版本**：V2.0.0
> **兼容性**：不向后兼容，需要升级集成

---

## 版本概述

V2.0.0 是 BlockATM 的重大版本升级，带来全新的收银台集成方式和 API 签名算法的全面升级。

{% hint style="warning" %}
**重要升级提示**：

- API 路径从 `/api/v1` 升级到 `/api/v2`
- 签名算法从 ECDSA 升级到 HMAC-SHA256
- Widget SDK 升级到 v2 版本

现有集成需要按照迁移指南进行升级。
{% endhint %}

---

## 主要变更

### 1. 收银台集成升级

#### 变更对比

| 变更项 | 旧版本 | 新版本 |
|--------|--------|--------|
| SDK 版本 | v1 | **v2** |
| SDK 地址 | `https://cashier.blockatm.net/libs/v2/BlockATM.umd.js` | **不变** |
| custNo 参数 | 可选 | **必填** |
| URL 签名 | 可选 ECDSA | **必填 HMAC-SHA256** |

#### 迁移步骤

```
1. 确认代码中是否传入了 custNo 参数
2. 集成 HMAC-SHA256 签名逻辑
3. 更新 SDK 引用路径
4. 测试验证
```

详细文档：[Widget SDK 集成](../integration/widget-sdk/integration.md)

---

### 2. 扫码支付集成升级

#### 变更对比

| 变更项 | 旧版本 | 新版本 |
|--------|--------|--------|
| 接入方式 | API 调用获取收银台 URL | **Widget 组件接入** |

#### 迁移步骤

```
1. 停用旧的 API 调用方式
2. 集成新的 Widget 组件
3. 移除旧的收银台 URL 跳转逻辑
```

详细文档：[收币集成指南](../integration/guides/collect-guide.md)

---

### 3. 付币 API 新增

#### 新增功能

| 功能 | 说明 |
|------|------|
| API 创建付币订单 | 新增 `/order/api/v2/payout/order` 接口 |
| 保留原上传方式 | 商户侧上传方式保留 |

#### API 文档

[创建付币订单 API](../integration/open-api/payout-api.md)

---

### 4. Webhook 升级

#### 变更对比

| 变更项 | 旧版本 | 新版本 |
|--------|--------|--------|
| 签名算法 | ECDSA | **HMAC-SHA256** |
| 状态字段 | 整数 (int) | **字符串 (String)** |

#### 状态码变更

| 旧状态码 | 新状态码 | 说明 |
|----------|----------|------|
| -1 | CANCELLED | 已取消 |
| -1 | EXPIRED | 已过期 |
| 0 | PENDING | 待支付 |
| 1 | SUCCESS | 成功 |

详细文档：[Webhook 签名验证](../integration/webhooks/verification.md)

---

### 5. API 路径升级

#### 变更对照表

| 功能 | 旧路径 | 新路径 |
|------|--------|--------|
| 获取支持网络 | `/api/v1/public/networklist` | `/api/v2/pub/allNetworks` |
| 获取支持代币 | `/api/v1/public/cryptocurrencies` | `/api/v2/pub/symbolList` |
| 获取收银台信息 | `/api/v1/contract/payment` | `/api/v2/pub/cashier/info` |
| 查询支付订单 | `/api/v1/payment/qrCodePayment` | `/order/api/v2/payorder/detail` |
| 查询付币订单 | `/api/v1/payout/get` | `/order/api/v2/payout/detail` |

---

## 字段变更详情

### Webhook 字段变更

| 旧字段 | 新字段 | 类型 | 说明 |
|--------|--------|------|------|
| platOrderNo | id | long | BlockATM 订单唯一标识 |
| type | orderType | int | 收币订单类型 |
| status | status | String | 状态：PENDING/SUCCESS 等 |
| walletAddress | fromAddress | String | 付款钱包地址 |
| merchantId | cashierId | long | 收银台 ID |
| - | blockTime | long | 区块链交易创建时间 |
| fee | - | number | 旧版手续费字段已移除 |

---

## 签名变更详情

### 配置位置变更

| 配置项 | 旧位置 | 新位置 |
|--------|--------|--------|
| API 公钥 | 收币合约 → 设置 → API | **收银台 → 集成** |
| API 密钥 | 收币合约 → 设置 → API | **收银台 → 集成** |
| Webhook 密钥 | 收币合约 → 设置 → Webhook | **收银台 → 集成** |
| Webhook 地址 | 收币合约 → 设置 → Webhook | **收银台 → 集成** |

### 签名算法变更

| 项目 | 旧版本 | 新版本 |
|------|--------|--------|
| 算法 | ECDSA | **HMAC-SHA256** |
| 排序规则 | 按字符排序 | **不变** |
