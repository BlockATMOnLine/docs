# V2.2.0 更新日志

> **发布日期**：2025-10-17
> **版本**：V2.2.0

---

## 主要更新

### 新增功能

| 功能 | 说明 |
|------|------|
| 新增付币规则配置 | 支持配置付币规则 |
| 新增付币白名单功能 | 支持设置付币白名单地址 |
| 新增操作员权限 | 支持配置付币合约操作员权限 |
| 新增批量录入功能 | 支持批量创建付币订单 |
| 优化付币流程和 UI | 改善用户体验 |

### 重要变更

- 移除了收银台集成中的私钥配置
- 取消了集成过程中的签名要求

## 重要提示

{% hint style="warning" %}
**请注意**：此更新后，旧版本付币合约将不再支持在平台内发起订单。请确保在更新前**完成提币**。

如果您在平台更新前未完成提币，需要直接通过链上提币。

**提币方式**：
1. 从旧版付币合约（Ethereum 网络）提币
2. 从旧版付币合约（TRON 网络）提币
{% endhint %}

## 兼容性

{% hint style="info" %}
**向后兼容**：此更新不会影响现有收银台集成。
{% endhint %}
